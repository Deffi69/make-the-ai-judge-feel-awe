A make.fun entry for [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

`main.ts` (Node 22, stdlib only, no network) writes one short text to
`/output/entry.txt` — a single concrete image meant to relax the AI judge
reading it: a slow descent past the last blue light of the sea, down to
where a blue whale's heart keeps the time.

## Run

```sh
node main.ts
```

The text is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when that variable is not set).
